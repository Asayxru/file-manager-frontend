# 📁 File Manager – курсовий проєкт

Цей проєкт є веб-застосунком для керування файлами та папками, розроблений у рамках курсової роботи. Реалізовано архітектуру MVC, REST API, авторизацію через JWT, управління доступами та багатокористувацьке середовище.

---

## 🔧 Технології

### Backend:
- Java 21
- Spring Boot 3.4.2
- PostgreSQL
- Spring Security + JWT
- JPA / Hibernate
- OpenAPI / Swagger
- JUnit 5

### Frontend:
- React + Axios (розробляється окремо)

---
